## ✨ Features

- **Elegant Letter Opening** — Click to open a beautifully animated digital letter
- **Word-by-Word Typing Animation** — Each line reveals with smooth motion
- **Emotional Design** — Custom "Runethia" font + premium dark theme
- **Background Music** — Soft, touching piano track (auto-loops)
- **Music Toggle** — Beautiful floating control with pause/play
- **Confetti Celebration** — Bursts when the letter opens
- **Fully Responsive** — Looks stunning on mobile & desktop
- **No Background on Letter** — Clean, floating letter on deep cinematic background
